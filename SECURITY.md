# Security Policy

To report a vulnerability, create a report here.

## Terms of Reporting

### 1. No AI Slop
If you use AI, you will be banned from the project. This rule exists to prevent abuse, which could lead to the deprecation of this repository.

### 2. No Fake Reports
Fake reports include reporting non-existent vulnerabilities.
If you want to report a bug, go to the **Issues** section and submit a proper bug report.

### 3. No Spam
Spamming means submitting a large number of security reports, which can cause chaos and annoy users.
